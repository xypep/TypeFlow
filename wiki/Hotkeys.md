# Hotkeys

| Taste | Wann | Funktion |
|---|---|---|
| `Tab` | während einer Session | neu starten (neue Zufallswörter bzw. gleicher Text bei `Full text`) |
| `Tab` | auf dem Ergebnis-Screen | `Again` / `Repeat` |
| `Esc` | während einer Session | abbrechen (Training: zurück zum Textfeld, Learn: zurück zur Übersicht) |
| `Backspace` | während einer Session | letztes Zeichen löschen |
| `Ctrl` / `Alt` + `Backspace` | während einer Session | letztes Wort löschen |
| beliebige Taste | Tippbereich hat keinen Fokus | Fokus zurückholen und weitertippen |

`Enter` wird beim Tippen ignoriert, weil Zeilenumbrüche zu Leerzeichen werden. Dead Keys wie `^` und `´` funktionieren wie in einem normalen Textfeld.
