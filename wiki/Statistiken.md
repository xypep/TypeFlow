# Statistiken (`Statistics`-Tab)

## Filter

- **Zeitraum:** `7 days` · `30 days` · `All`
- **Art:** `All` · `Training` · `Lessons`

Ist unter `Settings` ein Name eingetragen, steht er in der Überschrift (`Statistics · <Name>`).

## Kennzahlen

| Kachel | Bedeutung |
|---|---|
| `Sessions` | Anzahl Sessions im Filter |
| `Avg WPM` | Durchschnitt WPM |
| `Best WPM` | Bestwert |
| `Avg WPM (last 10)` | Durchschnitt der letzten 10 Sessions, zeigt den aktuellen Trend |
| `Avg accuracy` | Durchschnitt Accuracy |
| `Time typing` | gesamte Tippzeit |
| `Correct characters` | Summe korrekt getippter Zeichen |

## Charts

- **Speed:** WPM pro Session
- **Accuracy:** Accuracy in % pro Session

Mit der Maus über das Chart fahren, dann zeigt ein Tooltip WPM, Accuracy, Mode und Datum der Session.

## Problem keys (Heatmap)

Die Tastatur ist nach **Fehlerquote** eingefärbt: je oranger, desto mehr Fehler. Die Skala ist relativ zur schlechtesten Taste. Tasten mit weniger als 5 Anschlägen bleiben neutral. Hover zeigt Fehlerquote, Fehler und Anschläge.

Die Heatmap nutzt **alle** gespeicherten Daten (nicht den Filter). Gezählt wird nur der erste Versuch pro Zeichen, Korrekturen verfälschen das Ergebnis also nicht.

## History

Tabelle der letzten 50 Sessions: `Date`, `Mode`, `Text / lesson`, `WPM`, `Raw`, `Accuracy`, `Time`.
